# 😎 Little Game
  My second game project, in this one you're an emoji who's quest is to collect as many  
  stars as possible for whatever reason!

## ❔ How to Play
- Movement:  
Use A/D or <-/-> for horizontal movement and the Spacebar for jumping.

- Tips:  
Stars will randomly fall from the sky, and you must collect the yellow ones while  
avoiding the black ones, and if a yellow and black star collide with eachother a  
red star will appear, collecting it gives a massive score!

## 🚦 Running The Project
  1- Download and extract the .zip file.
  2- Search for the .exe file inside the folder.
  3- Run it and have fun!
